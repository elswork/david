Código Dart 3 Limpio, Inmutable y Tipado

Sin sobreingeniería dogmática de mappers inútiles. Un modelo único de verdad, inyección limpia de dependencias y reactividad pura con Riverpod y Firestore.

lib/kernel/david_plugin.dart 
abstract class DavidPlugin {
  String get id;
  String get name;
  List<Type> get dependencies => [];

  /// Fase 1: Registro de servicios en el contexto (ctx.provide<T>())
  Future<void> onLoad(DavidContext ctx) async {}

  /// Fase 2: Servicios de terceros listos; suscripción a eventos y rutas UI
  Future<void> onReady(DavidContext ctx) async {}

  /// Fase 3: Liberación de recursos y persistencia de colas
  Future<void> onDestroy(DavidContext ctx) async {}

  /// Rutas de navegación expuestas por el plugin al Shell central
  List<RouteBase> get routes => [];

  /// Herramientas y Recursos expuestos al protocolo MCP
  List<McpToolDefinition> get mcpTools => [];
}
lib/plugins/business/orders/data/orders_repository.dart 
/// Repositorio reactivo con persistencia local obligatoria y withConverter
class OrdersRepository {
  final FirebaseFirestore _firestore;
  const OrdersRepository(this._firestore);

  CollectionReference<Order> get _ordersRef =>
      _firestore.collection('orders').withConverter<Order>(
        fromFirestore: (snapshot, _) => Order.fromJson(snapshot.data()!),
        toFirestore: (order, _) => order.toJson(),
      );

  /// Flujo reactivo directo desde la caché local hacia la UI
  Stream<List<Order>> watchOrdersForRoute(String routeId) {
    return _ordersRef
        .where('routeId', isEqualTo: routeId)
        .orderBy('createdAt', descending: true)
        .snapshots(includeMetadataChanges: true)
        .map((snap) => snap.docs.map((d) => d.data()).toList());
  }
}

Pragmatismo Técnico

Principios Inquebrantables de Desarrollo

Rechazamos las modas pasajeras y el purismo académico que ahoga los proyectos en burocracia técnica. Programamos cimientos sólidos para durar décadas.

01 // REGLA FUNDAMENTAL

Pragmatismo sobre Dogma (Anti-Mappers)

Prohibido el desdoblamiento innecesario de modelos (`Dto` → `Model` → `Entity` → `UiState`). Un solo modelo inmutable en Dart 3 sirve directamente para la persistencia en Firestore, las reglas de negocio y las vistas Flutter.

02 // VELOCIDAD DE USO

La Regla de los Tres Toques

Si un operador comercial en ruta necesita más de tres toques para registrar un pedido o verificar una entrega habitual, la pantalla está mal diseñada. La velocidad y la ergonomía mandan sobre cualquier floritura visual.

03 // REALIDAD HOSTIL

Offline-First por Definición

Tratamos la conexión a internet como un accidente feliz, no como un requisito. Toda la aplicación opera contra caché local estructurada y sincroniza en segundo plano sin bloquear jamás la interacción humana.

04 // SOBERANÍA TECNOLÓGICA

Agnosticismo Agéntico Nativo

David no depende de ningún modelo de lenguaje propietario. Mediante el estándar universal MCP, el negocio conserva la soberanía total de sus datos y puede alternar entre LLMs en la nube o modelos locales privados.
